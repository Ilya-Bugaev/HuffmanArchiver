## О проекте

Консольный архиватор на языке C для сжатия и разжатия файлов без потерь на основе алгоритма Хаффмана. Приложение сжимает и восстанавливает файлы любых типов: текст, изображения, аудио и произвольные бинарные данные.

---

## Возможности

- Сжатие произвольных файлов по алгоритму Хаффмана
- Разжатие с восстановлением исходного содержимого
- Сохранение таблицы частот в заголовке сжатого файла
- Поддержка файлов любого размера и типа (текст, бинарные данные)
